## 2. Descripción del programa

Sistema de control de inventario para la tienda TecnoPunto, que permite registrar y mostrar información de los productos, validar sus datos y calcular el valor total de cada producto.

## 3. Datos de entrada
- Código del producto.
- Nombre del producto.
- Precio.
- Cantidad.

## 4. Datos que procesa
- Verifica que el nombre no esté vacío.
- Comprueba que el precio sea mayor que cero.
- Verifica que la cantidad no sea negativa.
- Calcula el ValorTotal multiplicando el precio por la cantidad.
- Maneja los datos inválidos mediante mensajes de error.

## 5. Datos de salida
- Código del producto.
- Nombre del producto.
- Precio.
- Cantidad.
- ValorTotal (precio × cantidad).

## 6. Capturas de ejecución

Las evidencias de las pruebas realizadas al programa se encuentran organizadas en la carpeta **Capturas**.

Esta carpeta contiene las siguientes pruebas:
- Ejecución con datos válidos.
- Introducción de un precio negativo.
- Introducción de un nombre vacío.
- Registro de un producto con cantidad cero.
